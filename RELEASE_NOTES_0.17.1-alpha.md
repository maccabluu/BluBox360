# BluBox 360 0.17.1 Alpha

## Online Name Sync Update

BluBox profile names and BluBox online names now stay together.

### New

- Added **Edit Name** directly inside Friends & Online.
- Your BluBox profile name is now also shown as your online name.
- Changing the name from Friends & Online updates the active BluBox profile.
- Your BluTag automatically changes its name part to match the new profile name.
- The four-number BluTag suffix stays linked to the same BluBox profile.
- Existing saves, achievements, friends, profile photo and library stay attached to the same profile.

### Online beta status

Friends and presence are still stored locally in this alpha. Remote account syncing and real internet friend requests need the future BluBox online backend.

This is a BluBox social system and does not sign into Xbox Live.
