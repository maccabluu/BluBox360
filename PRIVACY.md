# Privacy

BluBox 360 stores its game-library records, selected folders, artwork, settings,
local profiles, achievements, and emulator saves on the Android device.

The BluBox frontend has no advertising, analytics, BluBox account service, or
Xbox Live sign-in. The emulator core has Android network permission for guest
network compatibility. Network activity depends on the emulated software and
the selected settings.

Files attached to a public GitHub report are visible to other people. Remove
personal paths, account names, and other private information from screenshots
and logs before posting them.

Imported Vulkan driver packages contain native code. Use packages from a source
you trust.
