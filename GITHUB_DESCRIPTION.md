## Repository name

`BluBox360`

## Short repository description

BluBox 360 is a public alpha Xbox 360 emulator for ARM64 Android handhelds,
created by Macca and the BluBox team. Built around a Xenia-derived core with
Vulkan graphics, controller profiles, local saves and achievements, mods,
custom covers, and AYN Thor support.

## Public announcement

Hi, I am Macca. My team and I have been building BluBox 360, an Xbox 360
emulator for ARM64 Android handhelds. We are opening the project as a public
alpha so players and developers have a place to test games, report problems,
share device results, and help improve compatibility.

The alpha includes a Xenia-derived ARM64 core, Vulkan rendering, physical
controller support, profiles, local saves and achievements, mods, custom Xbox
360 covers, library folder scanning, AYN Thor features, and lower-heat presets.

This is early software. Some games do not boot. Others have graphical errors,
low frame rates, crashes, or high hardware load. Testers should use legal game
backups, keep save backups, start in Low Heat Mode, and submit clear reports.

BluBox 360 includes no games, Xbox firmware, encryption keys, or Microsoft
code. The project is independent and is not affiliated with Microsoft or Xbox.

Thank you to everyone who tests the alpha and helps our team improve BluBox 360.
