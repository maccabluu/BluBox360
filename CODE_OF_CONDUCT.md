# Community code of conduct

BluBox 360 welcomes respectful testing and development from people of every
background and experience level.

Be patient, discuss technical facts, respect different devices and test
results, and give credit for other people's work. Harassment, threats, hate
speech, deliberate misinformation, piracy requests, and sharing private data
are not accepted.

Project maintainers might edit, hide, or remove harmful content and restrict
accounts that repeatedly break these rules. Report conduct problems privately
to Macca through the [maccabluu GitHub profile](https://github.com/maccabluu).
