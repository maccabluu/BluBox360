# BluBox 360 0.17.2 Alpha

## BluBox Live Update

BluBox Live starts in this Android alpha as BluBox's own account and social identity system.

### New

- Friends & Online is renamed to **BluBox Live**.
- Each local BluBox profile can create a persistent BluBox Live account identity.
- BluBox Live Account ID stays linked to the same local profile.
- Copy your BluBox Live Account ID from the app.
- Your profile name remains your BluBox online name.
- BluTag, friends and Online/Away/Offline controls remain available.
- Existing saves, achievements, profile photos and game library remain linked to the same profile.

### Online service status

0.17.2 contains the account/session foundation in the Android app. The remote BluBox service is not deployed yet, so cross-device account syncing, remote friend requests, messages, invites and multiplayer are not live in this build.

BluBox Live is separate from Microsoft Xbox services. It does not ask for or store Microsoft/Xbox passwords and does not identify itself as Xbox Live.
