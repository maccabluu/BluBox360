# BluBox 360 0.13.0 public alpha

BluBox 360 0.13.0 adds an original startup sound when the app opens.

## New in this update

- Added a short original BluBox startup chime.
- The sound plays once when BluBox starts.
- Startup audio uses Android media audio, so the device media volume controls it.
- The startup sound is enabled by default.
- Existing boot animation, game library, 60 FPS target, Thor lower-screen telemetry, achievements, profiles, saves, renderer settings, and Fable II safety preset remain in place.

## Install

This is an ARM64 Android public alpha for Android 10 or newer with Vulkan support.

Back up important BluBox profiles and saves before installing an alpha build.

If Android refuses to install this build over an earlier BluBox alpha because the signing certificate differs, use BluBox 0.12.0 Settings > App > Back up app data first. Then uninstall the older alpha, install 0.13.0-alpha, and restore the backup.

Games, Xbox firmware, encryption keys, and Microsoft code are not included. Use legal game backups you own.
