# BluBox 360 0.16.2 public alpha

BluBox 360 0.16.2 is the Flat Cover Library Update, focused on making the game library cleaner and easier to browse.

## Flat cover library

- Flat front-cover artwork is now the default library style.
- Removed the plastic Xbox 360 case frame from game covers.
- Removed the green case border around cover artwork.
- Covers display the artwork itself without a fake box around it.
- Increased cover size so artwork is easier to see on handheld screens.
- Improved spacing between games for a cleaner library layout.
- Recently Played uses the same flat-cover style as the main library.
- All Games uses the same flat-cover style for a consistent look.

## Existing features

- HD+ graphics mode remains available.
- Retail cover import support remains available.
- Profiles, achievements, save-game progress and second-screen features remain included.
- Permanent BluBox signing and SHA-256 verification remain enabled.
- The updater fixes introduced in 0.16.1 remain included.

## Update notes

BluBox 360 is still in public alpha development. Back up important profiles and save data before installing a new alpha build.

Version: 0.16.2-alpha
Platform: ARM64 Android
