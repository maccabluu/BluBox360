# Security policy

## Supported version

Security fixes target the newest BluBox 360 public alpha. Older alpha builds
do not receive separate fixes.

## Reporting a security problem

Do not open a public issue for a flaw involving file access, code execution,
private data, update signing, or a malicious driver package. Contact Macca
through the [maccabluu GitHub profile](https://github.com/maccabluu) with a short
summary and wait for a private reporting route.

Do not include game files, firmware, encryption keys, passwords, or sensitive
personal data. A minimal reproduction using non-copyrighted sample data is
preferred.

Compatibility bugs, crashes from ordinary games, and graphics errors belong in
the public issue forms.
