# BluBox 360 macOS experimental engine notice

BluBox 360 macOS 3.0 Preview optionally bundles the experimental macOS builds from the open-source `wmarti/xenia-mac` project, release `v0.2.1`.

The bundled engine is Xenia-derived software and is not created by, affiliated with, or endorsed by Microsoft. Xenia source and binary redistribution is covered by its BSD 3-Clause license. A copy of the Xenia license is included with BluBox under `Contents/Resources/Licenses/XENIA-BSD-3-Clause.txt`.

BluBox's SwiftUI launcher, local library, settings, profiles, backup helpers, branding and integration layer remain separate BluBox project code.

The macOS engine is experimental. Compatibility differs by title and by host architecture. BluBox includes both the arm64 and x86_64 macOS engine builds so testers can switch between them.
